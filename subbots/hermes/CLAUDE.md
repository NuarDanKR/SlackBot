# Hermes — 이 저장소에서 일하는 법

> 이 파일은 Claude Code 가 세션마다 자동으로 읽습니다.

## 이 저장소가 무엇인가

Hermes 슬랙 봇의 **코드** 저장소입니다. **이것만으로는 안 돕니다.**

대화·문서 아카이브는 **팀마다 따로 만드는 별개 저장소**에 있고, `.env` 의
`HERMES_DATA_ROOT` 한 줄이 그것을 가리킵니다. 그 값이 비면 코드 저장소 옆
`hermes-archive` 폴더로 **조용히 물러섭니다** — 에러가 아니라 엉뚱한 폴더를 보는
상태라, 증상이 「config.json 이 없다」로만 나타납니다.

## 먼저 무엇을 하나

> 스킬이 자동으로 안 뜨면 `.claude/skills/hermes-install/SKILL.md` 를 열어 그대로 따라가세요.

| 지금 상태 | 하는 것 |
|---|---|
| 아직 설치 전 | **"헤르메스 설치"** — `hermes-install` 스킬이 0~8단계로 안내합니다 |
| 이미 돌고 있음 | **"아카이브 한 바퀴"** — `archive-run` 스킬 |
| 뭔가 이상함 | 설치 전이면 `npm run doctor`, 설치 후면 `npm run check` |

**절차는 이 파일에 없습니다.** 원본은 `README.md`(처음 설치) · `deploy/README.md`(VM) ·
각 스킬 폴더의 SKILL.md (예: `.claude/skills/hermes-install/SKILL.md`) 입니다.
여기 베끼면 원본이 바뀔 때 **에러 없이 낡습니다.**

## 일하는 규칙

- **커밋과 push 는 각각 따로 사람 승인을 받습니다.** 「고쳐줘」는 커밋 승인이 아니고
  「커밋해줘」는 push 승인이 아닙니다. 검증 목적도 예외가 아닙니다.
  `.githooks/` 의 관문이 받치지만 **관문은 켜져 있어야 돕니다** — `npm run doctor` 가
  그것을 봅니다
- **사실은 원본을 열어 확인한 뒤 씁니다** — 이름·금액·날짜·채널명. 확인 안 된 것은
  「확인 안 됨」으로 적습니다
- **사업장 이름과 비공개 채널 이름을 코드·주석·문서에 쓰지 않습니다.** 이 저장소는
  팀끼리 나눠 쓰는 곳입니다. `scripts/check-business-names.js` 가 잡습니다
- **우회를 썼으면 그 자리에서 말하고 `# WORKAROUND:` 로 표시합니다.** 조용히 넘어가면
  다음 사람이 그것을 정상 동작으로 읽습니다
- **다른 자리를 가리킬 때 행 번호로 적지 않습니다 — 함수·상수 이름으로 적습니다.**
  `foo.js:143` 은 그 위에 세 줄만 들어가도 **에러 없이 엉뚱한 곳**을 가리키고, 읽는
  사람은 그 줄을 근거로 판단합니다. **이 저장소에서 세 번 났습니다** —
  `src/ingest/git.js:143`(→147→155, 2026-09-07) · `src/claude.js:835`(2026-09-11 당시 —
  그 파일은 09-14 리팩터로 지금 103행이라 그 줄이 **아예 없습니다**) · 2026-09-21 에 한 번에 여덟 곳
  (`.claude/skills/doc-archive/scripts/review_batch.py:882` 는 그때 이미 1062행이었습니다). 가리킬 것이 줄 자체인 드문 경우(측정 증거 등)에는
  **잰 날짜를 함께** 적어 그 숫자가 시점값임을 밝힙니다
- **VM 배포는 두 걸음입니다** — 코드를 받고(`git pull`) 나서 재시작합니다. 15분마다
  도는 자동 pull 은 **자료 저장소만** 받아오고, 재시작 없이는 옛 코드가 계속 돕니다.
  그때 `git log` 에는 새 커밋이 보이고 pull 도 성공해서 **에러도 경고도 안 납니다**
- **봇이 VM 에서 도는 동안 노트북에서 `npm start` 를 하지 않습니다** — 같은 토큰으로
  둘이 붙으면 중복 응답·중복 요약이 납니다. 프롬프트 시험은 `--dry` 로 합니다

## 고쳤으면 돌리는 것

`npm run check` 하나입니다. 맨 앞 절이 코드 일관성 검사를 함께 돌립니다 — **두 곳에
나뉜 같은 판정이 갈렸는지**를 보는 것들이라, 갈려도 에러가 안 나고 숫자만 달라집니다.
사람이 알아채는 자리가 여기뿐입니다. 목록의 원본은 `scripts/check-setup.js` 의
`CROSS_CHECKS` 입니다.

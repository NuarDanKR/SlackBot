# TYBot 이용 안내 — 무엇을 보고, 무엇을 안 하는가

_임직원용 · 2026-09-01 · 이 문서는 그대로 공지에 붙여도 되게 썼다_

TYBot 은 사내 Slack 대화·첨부를 모아 두고, **그 원문만 근거로** 질문에 답하는 봇입니다.
아래는 봇이 하는 일과 하지 않는 일을 있는 그대로 적은 것입니다.

---

## 1. 답은 어떻게 만들어지나

```
질문 → 권한 확인 → 아카이브 원문 검색 → (0건이면 여기서 멈춤) → 답 작성 → 출처 부착 → 기록
```

- **근거를 못 찾으면 답하지 않습니다.** "추측으로 답하지 않습니다" 라고 말하고 멈춥니다.
  이때는 LLM 을 부르지도 않습니다.
- 모든 답변 끝에 **출처**가 붙습니다. `#채널, 📄문서(날짜)` 형식입니다.
  출처가 없으면 그것은 근거를 못 찾았다는 뜻입니다.
- 답변에 **근거 요약 한 줄**이 함께 나옵니다.

  > `_근거: 「김해외동 기성금」으로 검색 · 문서 3건 · 원문 12줄 사용 · claude-sonnet-5_`

- **`근거 보기`** 버튼을 누르면 그 답을 만들 때 실제로 읽은 원문 줄이 그대로 보입니다.
  숫자가 이상하면 원문을 직접 확인하세요. 봇 말보다 원문이 먼저입니다.

## 2. 봇이 보는 범위

| 보는 것 | 보지 않는 것 |
|---|---|
| 이름이 표준 규칙에 맞는 업무 채널 | 규칙 밖 이름의 채널, 잡담·개인 채널 |
| 봇이 멤버인 채널 | 봇이 초대되지 않은 비공개 채널 |
| **질문한 사람이 멤버인** 채널 | 그 사람이 못 보는 채널 |
| 사람이 검수해 승인한 첨부 원본 | 승인 전 첨부 |

**본인이 볼 수 없는 자료는 봇도 보여주지 않습니다.** 질문하는 사람마다 답의 근거가
다를 수 있습니다.

- `/권한` — 내가 받는 답이 무엇을 근거로 하는지
- `/수집상태` — 이 채널이 수집되는지, 아니면 왜 아닌지

## 3. 학습하지 않습니다

- 봇은 **매 질문마다 원문을 처음부터 다시 찾습니다.** 이전 대화를 기억하지 않습니다.
- **봇이 만든 답변은 다시 근거로 저장되지 않습니다.** 틀린 답이 사실처럼 굳는 것을
  막기 위해서입니다.
- 우리는 사내 대화로 모델을 **추가 학습(파인튜닝)하지 않습니다.**
- 외부 AI 제공사가 우리 데이터를 학습에 쓰지 않는다는 것은 **계약(DPA)** 으로 정합니다.
  코드가 아니라 계약의 영역이라는 점을 분명히 밝힙니다.

## 4. 올리면 안 되는 것

주민등록번호·등본류·개인이 특정되는 명단 같은 개인정보는 **채널에 올리지 마세요.**

봇은 이런 내용을 아카이브에 저장하지 않도록 거르지만, **그 거르기는 글자를 읽을 수 있을
때만 작동합니다.** 스캔한 이미지나 사진 속 개인정보는 걸러지지 않습니다. 그리고 걸러지든
아니든 **Slack 대화에는 그대로 남습니다.**

## 5. 첨부 파일

| 형식 | 처리 |
|---|---|
| PDF(스캔 포함)·이미지 | 검수 승인 후 **원본 그대로** 읽습니다. 출처에 페이지가 붙습니다 |
| Excel·PowerPoint·Word·한글 | 원본 전송이 안 되어 **추출한 텍스트**로 답합니다 |
| 그 외 | 파일이 있었다는 사실만 기록됩니다 |

원본으로 읽지 못한 파일은 답변에 그 사실을 함께 적습니다.

## 6. 답이 틀렸을 때

`/피드백` 을 쓰거나, 답변 스레드에 `@tybot 정정: 올바른 내용` 이라고 적어 주세요.

**신고는 담당자가 영업일 기준 2일 안에 확인합니다.** 원인이 확인되면 회귀 테스트로
만들어 같은 오류가 다시 나지 않게 하고, 결과를 그 대화로 회신합니다.

무엇이 틀렸는지 한 줄만 적어 주셔도 큽니다 — "틀렸다" 만으로는 고칠 거리가 남지 않습니다.

## 7. 사람의 감독

**답변 전에 사람이 검토하지는 않습니다.** 실시간으로 답해야 쓸모가 있기 때문입니다.
대신 이렇게 합니다.

| 시점 | 장치 |
|---|---|
| 답변 전 | 근거 0건이면 LLM 을 아예 부르지 않음 · 권한 필터가 모델보다 먼저 걸러냄 · PII 수집 거절 |
| 답변 중 | 원문에 없는 내용을 쓰지 못하게 하는 규칙 · 출처를 시스템이 부착 |
| 답변 후 | **모든 질문·답변·근거·비용이 기록됨** · 신고 창구 · 15분마다 아카이브 점검 |
| 첨부 | 원본을 외부로 보내기 전 **사람 승인** |

## 8. 이렇게 쓰면 됩니다

```
@tybot 김해외동 기성금 얼마야
@tybot 이번주 우리 팀 진행상황 정리해줘
@tybot 채널을 팀별로 쪼개는 게 나을까 하나로 둘까
/일정            오늘·내일 팀 일정
/일정 알림       회의 30분 전 개인 DM 받기
/채널 생성       표준 이름의 업무 채널 만들기
/수집상태        이 채널이 수집되는지
/권한            내 답변의 근거 범위
/피드백          답이 이상할 때
```

가장 잘 맞는 질문은 **"우리 기록 어딘가에 답이 있는데 어디 있는지 모르겠는"** 질문입니다.
일반 지식을 묻는 데는 적합하지 않습니다 — 그건 봇이 근거 없이 답하지 않습니다.

## 1. B-82 배포 커밋 확인

### 무엇을 묻나

`/opt/tybot` 에는 `.git` 이 없다(배포는 소스 체크아웃 `/var/lib/tybot/src` 에서
복사한다). 그래서 체크아웃의 `HEAD` 만 보면 **당겨만 놓고 배포는 안 된 상태**를
못 가른다. `c930f80` 이 실제로 바꾼 파일의 해시를 배포본에서 직접 잰다.

| 파일 | `c930f80` 기준 sha256 |
|---|---|
| `src/tybot/specialist_tools.py` | `6745e53c645f52ce5184db5b944c5601d995a475dd35f729e8448d36e97ee5c4` |
| `src/tybot/archive/vision_extract.py` | `203e7bd40ff6888135d64e66b107d54b1a3f087d08177cac943f361ed14c5836` |

### 명령

```bash
git -C /var/lib/tybot/src rev-parse HEAD
sha256sum /opt/tybot/src/tybot/specialist_tools.py /opt/tybot/src/tybot/archive/vision_extract.py
systemctl show tybot.service -p ActiveEnterTimestamp -p ExecMainStartTimestamp
```

### 결과 (2026-10-27)

**확인.** 배포본이 기준 커밋이다.

| 항목 | 값 | 판정 |
|---|---|---|
| `/var/lib/tybot/src` HEAD | `c930f80e1217989cd94d09bd07dd22d94a206e44` | 일치 |
| 배포본 `specialist_tools.py` | `6745e53c…97ee5c4` | **일치** |
| 배포본 `vision_extract.py` | `203e7bd4…d14c5836` | **일치** |
| `tybot.service` 기동 | 2026-10-27 13:29:00 KST | — |

체크아웃만이 아니라 **배포본 파일 해시가 맞았다** — 당겨 놓고 배포 안 된 상태가
아니다. 기동 시각은 2번에서 설정 파일 변경 시각과 대조할 기준이다.

## 2. 도구 시간 예산 실효값과 재시작 반영

### 무엇을 묻나

세 가지가 다를 수 있고, 다르면 **답변 경로가 설정과 다른 값으로 돈다.**

1. 설정 파일에 적힌 값
2. **돌고 있는 프로세스가 들고 있는 값** — 설정을 바꾸고 재시작을 안 했으면 다르다
3. `parse_tool_seconds` 가 15~120초로 **조인 뒤의 실효값** — 범위 밖이면 조여진다

프로세스 환경은 토큰이 같이 들어 있다. **통째로 찍지 말고** 이 변수만 꺼낸다.

### 먼저 틀린 방법 (기록해 둔다)

`/proc/<pid>/environ` 과 `/etc/tybot/tybot.env` 만 보면 **답이 안 나온다.**

콘솔은 원본 환경파일을 안 건드리고 `STATE_DIR/config/console-managed.env` 에
쓴다. 그 파일은 [`envfile.py`](../../src/tybot/envfile.py) 가 **런타임에**
`override=True` 로 올린다 — `/proc/<pid>/environ` 은 exec 시점 환경만 담으므로
거기에는 **영영 안 나타난다.** 「없음」 이 「설정 안 됨」 을 뜻하지 않는다.

그래서 **봇과 같은 로더(`load_env_file()`)를 태워서** 재야 한다.

### 결과 (2026-10-27)

| 항목 | 값 |
|---|---|
| 로더가 읽은 파일 | `/etc/tybot/tybot.env` (오버레이 없음) |
| `TYBOT_SPECIALIST_TOOL_SECONDS` 원시값 | `None` — **설정된 적 없음** |
| `configured_tool_seconds()` | **90.0** |
| 콘솔 오버레이 파일 | 없음 |
| 재시작 대기 | 없음 |
| `/etc/tybot/tybot.env` | 72줄 중 이 변수 **미존재**, mtime 2026-10-15 14:29 (기동보다 앞) |

**실효값 90초는 확인했다.** B-82 가 정한 기본값과 같다. 2026-10-21 장애 당시의
45초가 아니다.

### 재시작 반영은 **검증 불가**

값이 기본값이고 콘솔로 **바꾼 적이 없다.** 바뀐 설정이 없으므로
「재시작이 반영하는가」 는 이번에 잴 수 없었다. 재려면 콘솔에서 값을 한 번
바꿨다 되돌리는 **운영 설정 변경**이 필요하고, 그것은 이번 검증 범위 밖이다.

이번에 확정된 것은 **지금 도는 값이 90초**라는 것뿐이다. 3~6번은 이 값 위에서
잰 것이 된다.

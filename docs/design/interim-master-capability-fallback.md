# 전문 봇 도입 전 마스터 임시 역할

> 2026-09-17 오너 결정. B-52~55 전문 봇이 운영 등록되기 전까지만 적용한다.

## 목적

전문 봇이 없다는 이유만으로 사용자의 실제 의도를 버리지 않는다. 다만 마스터에게
외부 조회나 법률 판단 능력이 생긴 것처럼 가장하지 않는다. 임시 역할은 **이미 허용된
원문과 일반적인 판단** 안에서만 수행하고, 전문 봇이 등록되면 해당 경로를 제거한다.

## 임시 처리표

| 요청 | 임시 처리 | 금지 |
|---|---|---|
| TYBot 답변·검색 방식에 대한 자연어 의견 | `feedback`으로 분류해 `/피드백`과 같은 원장에 기록하고 접수 사실을 답한다 | 아카이브 근거로 사용 |
| 사내 문서 요약 + 판단·조언 | Hermes가 권한 내 원문으로 답한 뒤 마스터가 같은 원문 범위로 임시 코멘트를 추가한다 | Hermes 문장을 원문으로 재사용, 새 사내 사실 추정 |
| Clio 장문·발표문 | Hermes의 3,000자 이내 핵심 정리까지만 제공 | 장문 완료로 가장, Hermes 상한 확대 |
| 최신 외부 제품 정보 | 공식 조회 전문 봇·도구가 없음을 밝히고 필요한 공식 URL/자료를 요청 | 모델 기억으로 최신 사실 작성 |
| 법령·준수 판단 | 공종·지역·단계 등 확인 질문과 일반 검토 항목만 제공 | 조문·시행일·적법 여부를 추측 |

## 판단·조언 출력 계약

1. Hermes 결과는 `Hermes`가 작성한 근거 답변으로 유지한다.
2. 추가 부분은 `TYBot 임시 판단·조언`으로 눈에 보이게 구분한다.
3. 마스터 입력은 Hermes 답변이 아니라 동일한 ACL 필터 원문이다.
4. QA의 최종 응답 주체는 `master-interim`, 시도 전문 봇은 `hermes`로 남긴다.
5. 판단 전문 봇이 활성화되면 Hermes 대상 임시 분기를 제거하고 전문 봇 결과를 쓴다.

## 피드백 계약

`/피드백` 명령을 사용하지 않아도 “과거 자료 대신 최신 자료를 먼저 찾아야 한다”,
“방금 답변은 다른 현장 내용이다”처럼 TYBot 동작을 평가하는 문장은 `feedback`이다.
직전 본인 답변에 연결하되 찾지 못해도 신고 자체는 저장한다. 응답에는 피드백으로
판단해 접수했다는 사실과 답변 근거로 사용하지 않는다는 정책을 함께 표시한다.

## 제거 조건

- 판단·권고 capability를 가진 승인 전문 봇이 등록되면 Hermes+마스터 임시 분기를 제거한다.
- B-54/B-55는 공식 Web/Law EvidenceRef 도구가 준비되기 전까지 사실 답변으로 대체하지 않는다.
- 제거 전후 회귀 테스트에서 ACL, 출처, 최종 응답 주체가 유지되어야 한다.

# 안내 화면 캡처

`워크스페이스 관리` 화면의 Slack 앱 만들기 안내에 붙는 이미지입니다.
파일이 없으면 이미지 자리는 그냥 비어 있습니다(오류가 나지 않습니다).

| 파일명 | 찍을 화면 |
|---|---|
| `01-create-app.png` | api.slack.com/apps → Create New App → From an app manifest 선택 |

| `03-bot-token.png` | OAuth & Permissions 의 Bot User OAuth Token 위치 |

## 캡처할 때 지킬 것

- **토큰 값이 화면에 보이지 않게** 가리고 찍어 주세요. `xoxb-`/`xapp-` 로 시작하는 값이
  이미지에 남으면 저장소에 토큰을 커밋하는 것과 같습니다.
- 워크스페이스 이름·구성원 이름이 함께 찍히면 지워 주세요.
- 가로 1200px 내외면 충분합니다.

Slack 앱 관리 화면은 로그인해야 보이므로 캡처는 사람이 찍어야 합니다(BACKLOG B-18).

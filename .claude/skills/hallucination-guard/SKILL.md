# 환각 방지 4겹 (기존 Hermes 봇에서 계승)

## 1겹 — 근거 오염 금지
- 봇 답변을 아카이브에 재저장 금지(요약 재귀 방지).
- 원문 불변, `[정정]`으로만 교정. 근거는 Slack 한정.

## 2겹 — 답 전에 반드시 원문 열기
- 색인(목차)은 "어디를 볼지"만 알려줄 뿐 근거가 아니다. 구체 질문엔 **반드시 도구로 원문 검색** 후 답한다.
- 금액·날짜·기관명·사람 이름 = 추론/반올림 금지, 적힌 그대로.
- "그럴듯하게 지어내는 것은 모른다고 하는 것보다 나쁘다"를 시스템 프롬프트 첫머리에.
- 직전 자기 답변을 근거로 재사용 금지 — 매번 처음부터 검색.

## 3겹 — "없다"를 함부로 말하지 않기
답을 4갈래로 구분:
| 상황 | 답변 |
|---|---|
| 정말 없음 | "아카이브에 없습니다" + 어디를 볼지 |
| 권한 없음 | "열람 권한이 없어 확인 불가" (채널명도 안 밝힘) |
| 파일 있으나 미변환 | "그 자료는 엑셀이라 아직 변환되지 않았습니다" |
| 목차에 안 보임 | "없다" 금지 — 먼저 검색 |
- **검색 0건이면 해당 사업장 문서 제목 목록을 함께 반환**(군포 사고 교훈: 봇에 필요한 건 "다시 시도하라"가 아니라 목록).

## 4겹 — 사람이 잡아낼 수 있게
- 출처 강제(`출처: #채널, 📄문서(날짜)`). 목차만 보고 답하면 출처 못 달게 → 출처 없는 답 = 근거 없는 답.
- 사람 발언 ↔ 문서 분리, 엇갈리면 두 시점 병기.
- 스캔(OCR) 문서 인용 시 "원본 확인 권함" 부기.
- 아카이브 형식 검사 매번(조용한 0건 = 가장 위험한 환각 경로).
- 질문·답변·근거(열어본 채널/문서/검색어) 전부 로깅 → 사고 역추적 가능.
- 권한은 막는 쪽이 기본값.

## 리뷰 체크리스트
- [ ] 답변 경로에 출처 강제가 있는가
- [ ] 검색 0건 시 제목 목록 폴백이 있는가
- [ ] 권한 필터가 답변 생성 "이전"에 적용되는가
- [ ] 봇 출력이 아카이브로 되먹임되지 않는가

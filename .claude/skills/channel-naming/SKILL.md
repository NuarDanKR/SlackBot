# 채널 명명 규칙

## 표준
`#<구분>_<이름>(<코드>)_<업무명>`

| 유형 | 예시 |
|---|---|
| 팀 채널 | `#팀_자금(ABB540)_주간보고`, `#팀_토목(ABB540)_현안관리` |
| 현장 채널 | `#현장_김해외동(180182)_채팅방`, `#현장_김해외동(180182)_DFSM` |
| 공통 채널 | `#전사_공지`, `#전사_메뉴얼` |

## 정규식(검증)
```
^#(팀|현장|전사)_[^()]+(\([0-9A-Z]+\))?_?.*$
```
- 팀/현장 채널은 조직·현장 **코드**를 괄호로 포함해야 봇이 워크스페이스/ACL에 매핑 가능.
- 공통(`#전사_`)은 코드 생략 가능.

## 목적
- 채널명만으로 담당 조직·업무·현장 식별 → AI 자동 분류·검색·권한 매핑.
- 중복/유사 채널 난립 방지.

## 사용
- 새 채널 생성/`/new-workspace` 시 이 규칙으로 이름을 검증하고, 위반 시 교정안을 제시.
- 봇 초대(`/invite @tybot`)가 채널 생성 직후 첫 액션임을 함께 안내.

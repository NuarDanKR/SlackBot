# 채널 명명 규칙

## 표준
`#<두문자>-<조직명>_<조직코드>-<업무>`

| 예시 | 뜻 |
|---|---|
| `#팀-전산_ABB110-주간회의` | 전산팀(ABB110) 주간회의 |
| `#본부-건축_AB-경영회의` | 건축본부(AB) 경영회의 |
| `#현장-김해외동_180182-채팅방` | 김해외동 현장(180182) |
| `#프로젝트-스마트팩토리_PJ2026-킥오프` | 프로젝트 |

**수집 대상 두문자**: `본부` `실` `팀` `현장` `프로젝트`
이 다섯 중 하나로 시작하면 봇이 **초대 없이 스스로 참여해 수집**한다(공개 채널).
아니면 수집하지 않는다 — 잡담·개인·외부 협업 채널을 이름만으로 걸러내는 장치다.

## 왜 코드를 넣나
조직명은 개편으로 바뀌지만 **코드는 유지**된다. 수집된 MD 프론트매터에
`org_code`·`org_kind`·`org_name` 이 기록되므로, 조직 개편이나 워크스페이스 통합 뒤에도
그 문서가 어느 조직 것이었는지 추적할 수 있다.

## 구형식은 폐기됨
`#팀_자금(ABB540)_주간보고` 같은 괄호 형식은 **더 이상 인식하지 않는다.**
그런 이름의 채널은 수집 대상이 아니다. 이미 수집된 문서는 남지만 새 수집은 멈춘다 —
이름을 신형식으로 바꾸면 `channel_rename` 이벤트로 그 순간부터 다시 수집된다.

조직코드는 **필수**다. 코드가 없으면 조직 트리에 붙일 수 없어 규칙 위반으로 본다.

## 검증
```python
from tybot.channels import parse, should_collect, explain
should_collect("#팀-전산_ABB110-주간회의")   # True
explain("#점심메뉴")                          # 왜 대상이 아닌지 + 올바른 형식 안내
```

## 비공개 채널 — Slack 제약
**봇 토큰으로는 비공개 채널에 자가 참여가 불가능하다.** `conversations.join` 은 공개 채널
전용이고, 봇은 자기가 없는 비공개 채널을 목록 조회조차 못 한다. 우회 경로가 없다.

| 방법 | 조건 |
|---|---|
| 사람이 `/invite @tybot` | 채널 멤버 아무나 |
| `scripts/invite_bot.py` 일괄 초대 | 관리자 사용자 토큰(`xoxp-`) + **그 관리자가 그 채널 멤버**여야 함 |
| `admin.conversations.invite` | Enterprise Grid 플랜 |

관리자 토큰은 워크스페이스 전반 권한을 갖는 자산이라 **봇 프로세스에 저장하지 않는다.**
스크립트가 실행 시 환경변수로만 받는다.
- 채널을 만들 때 이름을 잘못 지었다가 나중에 고쳐도 된다 — `channel_rename` 이벤트로
  그 순간부터 수집이 시작된다. 다만 **이름 변경 이전 대화는 백필 한계**(요청당 15건)를 받는다.
